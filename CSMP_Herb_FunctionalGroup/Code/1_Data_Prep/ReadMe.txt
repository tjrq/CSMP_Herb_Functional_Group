The folder labeled "Data" has the metadata of fish assemblages across depths in the Coral Sea Marine Park. 

For my thesis, I only required data on herbivorous fishes and so subsetting of data was conducted using the R quarto document called "data_prep". In that quarto document, abundance, biomass and richness of herbivorous fishes, together with explanatory variables were extracted and subsequently uploaded in the "Exported_Data" folder.

In the "Exported_Data" folder, there are 4 csv files that contain data used for the analyses of changes in herbivore abundance, biomass, richness and assemblages across depths.
