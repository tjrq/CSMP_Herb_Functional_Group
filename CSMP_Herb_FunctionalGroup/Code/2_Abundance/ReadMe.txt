Model fits are in the quarto file labelled "abun_model_fit". This quarto document has the code for all the analyses conducted on fish abundance. The quarto document labelled "abun_results_plots" contains code on the interpretation and figure generation using the models from the "abun_model_fit" file. Bayesian model outputs are saved in the folder named "Model_Output".

In the "abun_results_plots", certain folders related to figure generation: "Images" and "Figures" were deleted for data archiving. These folders simply contained fish silhouettes and stored the ggplot figures, respectively.
