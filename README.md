# CSMP_Herb_Functional_Group

This repository contains data (in csv files) and R codes (in quarto documents) when examining differences in species richness, abundance, and biomass of herbivorous fishes collectivity and among functional groups (browsers, croppers, detritivores, excavators, scrapers) along a depth gradient of 2- 98m in the Coral Sea Marine Park, Australia. The data has been published in Coral Reefs (10.1007/s00338-025-02764-0)
