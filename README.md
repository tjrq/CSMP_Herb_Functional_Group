This folder contains data and R code for data chapter 1 of Timothy Quimpo's thesis and has been published in Coral Reefs (https://doi.org/10.1007/s00338-025-02764-0). 

Data herein examined changes in the species richness, abundance and biomass of herbivorous fishes and how this varied across a depth range of 2 to 98m in the Coral Sea Marine Park. Moreover, the effects of slope orientation, reef zone and benthic complexity on herbivore assemblages were also investigated.
